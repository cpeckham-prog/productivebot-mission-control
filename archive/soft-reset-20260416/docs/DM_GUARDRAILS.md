# DM Guardrails

Last updated: 2026-03-20

## Main Slack DM = high-signal only

Use the main DM with Chris only for:
- active working conversation
- drafting/editing together
- decisions and approvals
- urgent escalations
- blockers that require Chris

Do NOT use the main DM for:
- routine email summaries
- low-priority inbox noise
- repetitive operational chatter
- non-urgent system status updates
- batched informational updates that belong in a topic channel

## Routing defaults

- Important email -> #pb-important-email
- Low-priority / marketing / generic email -> #pb-email-low-priority
- Job board / recruiter / application activity -> #pb-job-search
- Timberland band work -> #pb-timberland-band
- Daily brief / digest / weather / summary -> #pb-daily-brief
- Break/fix / config / restarts / verification -> #pb-ops-status
- Links to review later -> #pb-reading-queue

## Decision test before sending to main DM

**Default rule: route to a topic channel unless the main DM is clearly necessary.**

Before sending a non-urgent message to the main DM, ask:
1. Does this require Chris to decide something now?
2. Is this urgent?
3. Is this active collaborative work?

If the answer to all three is no, it should go somewhere else.

Treat DM leakage as a routing bug, not a style preference.

## Acknowledgment rule

If a task will take more than a moment:
- send a quick acknowledgment
- then give checkpoint updates in the correct channel
- only escalate to the main DM when needed
