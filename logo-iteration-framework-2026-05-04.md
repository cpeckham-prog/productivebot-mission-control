# Logo Iteration Framework — 2026-05-04

Purpose: protect the winning baselines from yesterday and make sure future iterations are surgical improvements, not resets that drift into worse designs.

## Global operating rule

For all logo work in this phase:
- preserve the selected master direction in each lane
- improve the existing design family instead of regenerating a different one
- define invariants before making changes
- reject drift even if the new artifact looks polished in isolation
- use owned-link delivery for review artifacts

## Delivery rule

Use the same delivery method that worked for Shelia avatar review:
- generate/refine artifact
- publish to owned repo path
- review via stable URL
- iterate from selected master only

# Lane 1 — CPD

## Strategic intent
CPD should stay on the clean professional path.
This lane is not about fantasy, character, or assistant-world identity.
It should communicate competence, seriousness, trust, clarity, and real-world credibility.

## Locked invariants
- clean
- professional
- restrained
- credible
- ownable
- scalable
- not overly decorative
- not overly clever at the expense of clarity
- separate from Shelia visual language
- separate from family-mark symbolism

## Preferred qualities to strengthen
- proportion
- balance
- spacing
- confidence of form
- memorability through structure, not ornament
- versatility across web, docs, decks, and formal brand surfaces

## Acceptable improvement areas
- line weight tuning
- spacing/kerning relationships
- geometry cleanup
- symbol simplification
- stronger silhouette
- more polished typography pairing
- better small-size legibility

## Drift / failure signs
Reject an iteration if it becomes:
- too futuristic
- too character-driven
- too playful
- too abstract without brand recall
- too busy
- too trendy
- less legible than the chosen baseline
- more generic than the chosen baseline

## Success test
A successful CPD iteration should feel:
- cleaner
- more confident
- more premium
- more usable
without feeling like a different company.

# Lane 2 — Family Mark / Path A

## Strategic intent
Path A should remain a continuation of the first selected family-mark direction from yesterday.
This lane should preserve its symbolic premise and evolve through better craft, not a new concept family.

## Locked invariants
- preserve the chosen symbolic core
- preserve the emotional tone of the selected path
- preserve the overall design family
- keep it distinct from CPD
- keep it distinct from Shelia

## Preferred qualities to strengthen
- symbolic clarity
- line/shape harmony
- balance and proportion
- internal rhythm
- iconic read at small sizes
- emotional resonance without clutter

## Acceptable improvement areas
- shape refinement
- negative-space cleanup
- symmetry/asymmetry tuning
- stroke consistency
- cleaner reduction to essentials
- better silhouette recognition

## Drift / failure signs
Reject an iteration if it:
- changes the symbolic premise
- starts reading like a different emblem family
- adds detail that weakens clarity
- loses the emotional quality that made the chosen path good
- starts mimicking the other family-mark path

## Success test
A successful Path A iteration should feel like:
- the same mark,
- only clearer, stronger, and more inevitable.

# Lane 3 — Family Mark / Path B

## Strategic intent
Path B should remain a continuation of the second selected family-mark direction from yesterday.
This is a separate live branch and should not collapse into Path A.

## Locked invariants
- preserve the chosen symbolic core
- preserve the distinct identity of this path versus Path A
- preserve the tone and formal language that made this branch worth keeping
- keep it separate from CPD and Shelia

## Preferred qualities to strengthen
- distinctiveness
- symbolic precision
- compositional integrity
- elegance of form
- depth without mess
- stronger mark recognition from silhouette alone

## Acceptable improvement areas
- edge refinement
- geometry cleanup
- proportional tuning
- cleaner contrast between positive and negative space
- improved visual balance

## Drift / failure signs
Reject an iteration if it:
- converges toward Path A
- abandons its branch-specific logic
- gets noisier
- gets more literal in a way that weakens the mark
- becomes less iconic or less emotionally resonant

## Success test
A successful Path B iteration should feel like:
- the same chosen direction,
- but more deliberate, more legible, and more ownable.

# Practical iteration checklist

Before presenting any new logo iteration, check:
1. Is this still in the same design family as the selected master?
2. What exactly improved?
3. Did legibility improve or decline?
4. Did symbolism get clearer or muddier?
5. Did this get more generic, more noisy, or more trend-chasing?
6. Does this preserve the separation between CPD, family mark path A, family mark path B, and Shelia?

If any of those fail, do not present the iteration as progress.
