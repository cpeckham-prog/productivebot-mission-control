# Timberland Band Budget Dashboard

Standalone working dashboard for the 2026-27 Timberland Band budget process.

Open `index.html` in a browser, or use the GitHub Pages path `/timberland-budget/` once deployed.

Included resources:
- `tuesday_workshop_assumptions.csv`
- `tuesday_decision_log.csv`
- `meeting_actuals_variance_view.csv`
- `structure_actuals_comparable_model_v2.csv`
- `next_phase_resource_packet.md`

The dashboard stores local edits in browser localStorage and can export edited tables as CSV.
