# Timberland Band Treasurer Operating Build — Next Phase

## What this phase is building

A practical two-year operating system for the booster budget, not just a Tuesday spreadsheet. The dashboard and resources are designed to mature across the 2026-27 and 2027-28 school years.

## Tuesday-ready resources

1. **Editable dashboard** — live inputs for fee/fundraising/program assumptions, plus decision log and risk view.
2. **Assumptions CSV** — the baseline assumptions to review and change.
3. **Decision log CSV** — the meeting control sheet for open budget choices.
4. **Actuals/variance source views** — existing extracted files stay linked as evidence.

## Recommended meeting posture

Open with: “My goal is to make this easier and more reliable for the program. We do not need a fake final number today. We need to agree on structure, scope, known commitments, and the assumptions that let us build a board-ready budget.”

## Two-year operating arc

### 2026-27: stabilize and make reality visible
- Confirm budget architecture and approved baseline.
- Separate operating, program, pass-through, and restricted money.
- Start monthly budget-vs-actual review.
- Create a clean decision/approval path for unbudgeted commitments.
- Build conservative/base/stretch fundraising model.

### 2027-28: optimize and grow
- Use prior-year actuals to set the budget earlier.
- Establish grant calendar and sponsor packages.
- Build reserve targets for uniforms, instruments, props, truck/trailer, and competition growth.
- Move from reactive fundraising to owner-based campaigns with dates, targets, and net contribution tracking.
