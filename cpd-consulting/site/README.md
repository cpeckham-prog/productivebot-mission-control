# CPD Operating Group site draft

Lightweight one-page static website draft for CPD Operating Group.

## Files

- `index.html` — self-contained HTML/CSS landing page for a credible executive consulting presence.
- `cpd-logo.svg` — copied from the approved CPD logo asset at `mission-control-dashboard/logo-assets/cpd-final-approved-lockup-clean-v2.svg`.

## Positioning reflected

The copy positions CPD around B2B go-to-market and revenue operations advisory, with emphasis on:

- turning founder-led sales into a repeatable commercial engine
- GTM clarity and commercial operating discipline
- sales process, CRM hygiene, pipeline inspection, and forecasting
- AI-enabled revenue operations where it improves real workflows
- practical operating support rather than overbuilt consulting collateral

## Usage

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd /Users/productivebot/.openclaw/workspace/cpd-consulting/site
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

No external deployment has been performed.
